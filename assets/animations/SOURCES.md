# Bundled Lottie animations — source & license

These animation JSON files were downloaded from the official `lottie-flutter`
package example assets (xvrh/lottie-flutter, MIT-licensed repository) and are
used as interaction-feedback motion only:

| File             | Used for                         | Source (raw GitHub, xvrh/lottie-flutter `example/assets`) |
|------------------|----------------------------------|-----------------------------------------------------------|
| loading.json     | loading/spinner states           | pass_loading.json                                         |
| celebration.json | prayer-complete / streak success | 17297-fireworks.json                                      |
| email.json       | email-verification screen        | envelope.json                                             |

NOTE FOR STORE SUBMISSION: verify each file's individual licence before
publishing. They ship with the MIT-licensed lottie-flutter example repo, but
some originate from LottieFiles community uploads — confirm attribution
requirements for your release. Replace any file here with your own licensed
animation and the app will pick it up automatically (same filename).
